# Generated presentation imagery

Created 28 October 2026 using the built-in image_gen tool in generate mode. No stock downloads, image server, new account or paid client service is required. All eleven selected originals are saved in design/imagery/source and optimized bundled versions are in assets/images.

The food, city and fictitious driver photographs are illustrative demo images, not photographs of participating merchants or an assigned real driver. The supplied ZemenGo brand logo is unchanged. The cars and parcel retain transparent backgrounds. Optimization changes encoding and size only; originals are preserved.

The application uses these images on onboarding, home service cards, the city banner, vehicle choices, driver details, the moving map vehicle, restaurant cards/menus and the package header.

The machine-readable manifest is [manifest.json](../design/imagery/manifest.json).
